# DailySync для Kobo Forma 4.38.23828 — пробная версия 0.1.2

Синхронизация штатной читалки с уже настроенным сервером Autocaliweb при первом
пробуждении за календарный день, затем отключение Wi-Fi. Первая загрузка после
включения питания также считается пробуждением.

**Статус:** личный экспериментальный проект. Разработка и испытания ограничены
Kobo Forma с прошивкой 4.38.23828. В версии 0.1.1 журнал устройства подтвердил полный
обмен и пропуск повторного автоматического запуска в тот же день, а пользователь
подтвердил отключение Wi-Fi. В 0.1.2 на устройстве проверен ручной запуск при
включённом моде: сервер получил запрос, интерфейс завершил обмен без ошибки,
после него Wi-Fi отключился. Ожидаемых обновлений при этой проверке не было.

**Известное ограничение:** эта ручная попытка не обновила штатную отметку полного
успеха, поэтому в журнале мода остались `UNCONFIRMED` и `FAILED`. Доступ ручного
запуска и отключение сети подтверждены; учёт полного успеха этой попытки ещё требует
уточнения. Эти строки сами по себе не доказывают сбой обмена. Экономия заряда не измерялась.

## Изменение 0.1.2

Штатная кнопка синхронизации Kobo теперь получает отдельное разрешение на одну
попытку, даже если сегодня уже был успешный автоматический обмен. Мод ждёт её
завершения и выключает Wi-Fi; вторую синхронизацию вместо штатной не запускает.
Дневной лимит остаётся только у автоматического запуска.

Пункт **Daily Sync - sync now** работает и на паузе: выполняет одну попытку с
последующим отключением Wi-Fi, оставляя автоматическое расписание на паузе.
Штатная кнопка при включённой паузе работает обычным образом, без управления сетью модом.

## Исправление 0.1.1

Первая версия ошибочно вызывала внутренний этап `startUserSync()` напрямую.
В журнале устройства был `SYNCING`, но это подтверждало лишь вызов функции.
В 0.1.1 используется штатный `silentSync()`, который проходит через тот же виртуальный
полный запуск `sync()`, что кнопка синхронизации Kobo. Этот путь проверен по коду и
таблице виртуальных методов официальной прошивки.

Теперь журнал различает `REQUESTING`, `START_RETURNED`, `STARTED` (штатный сигнал
`syncStarted`) и `SUCCESS_SIGNAL`. Без сигнала начала ожидание ограничено 20 секундами,
после чего выполняются отмена и отключение Wi-Fi. Во время попытки каждые 10 секунд
пишется состояние ожидания. После подключения по USB таймеры останавливаются —
последняя строка перед подключением сама по себе не означает зависание.

**Обновление с предыдущей версии:** скопируй только `.kobo/KoboRoot.tgz` из нового архива в Kobo,
извлеки диск и дождись перезагрузки. Существующие настройки и журнал сохранятся.
Обновление создаёт файл `paused`. Удали его или выбери `Daily Sync - resume` после
перезагрузки. Повторно копировать `.adds` для обновления не требуется.

## Поведение

- После пробуждения ждёт 5 секунд, подключается к известной Wi-Fi сети и вызывает
  штатный тихий запуск полной синхронизации Kobo.
- Использует существующую настройку Autocaliweb. Адрес сервера, токен, библиотеку
  и учётную запись заново вводить не нужно. Прямых записей в базы книг нет.
- Отмечает день успешным только после вызова штатного `setLastSyncTime`, сигнала
  завершения и окончания штатной очистки. Обновление одной книги не засчитывается.
- После успеха отключает Wi-Fi. Другие пробуждения в этот день синхронизацию не запускают.
- Если сети нет, максимум через 60 секунд завершает попытку. Синхронизации даётся
  до 20 секунд на подтверждение начала, затем до 5 минут на сам обмен; после превышения
  лимита запрашивается штатная отмена с ожиданием до 15 секунд и отключением сети.
  При очень большой загрузке книг лимит нужно увеличить или временно включить паузу.
- После неудачи повторяет при следующем пробуждении. Постоянных повторов в фоне нет.
- Не создаёт будильников и не держит процессор работающим во сне. Таймер опроса раз
  в секунду работает только во время попытки. После неё остаются событийные обработчики.
- Во включённом режиме блокирует Wi-Fi вне автоматической или явно запрошенной
  ручной синхронизации. Штатная кнопка синхронизации разрешена; для браузера,
  Wikipedia и прочих сетевых функций нужна пауза.
- Если при подключении Wi-Fi сам Kobo уже начал обмен, мод дожидается его и затем
  запрашивает свой полный обмен. Один ежедневный запуск может давать несколько HTTP-запросов.
- Во время передачи диска по USB управление приостанавливается; данные настроек
  в экспортированный раздел не записываются.
- Работает только внутри штатной программы Kobo, не управляет сетью KOReader/Kobalt.
- Проверяет модель Forma (377/380) и точную версию 4.38.23828. Для других версий
  автоматизация остаётся неактивной; после смены прошивки пакет требует пересмотра.

## Установка

Сброс и восстановление старой базы не нужны. Существующий бэкап сохрани.

Скачай установочный ZIP из [Releases](https://github.com/kroshka4aplin/kobo-autosync/releases).
Автоматический архив GitHub «Source code» для установки не подходит.

1. Распакуй установочный ZIP на компьютере и включи отображение скрытых файлов.
2. Подключи Forma по USB. Сначала скопируй `.adds` из архива в корень диска Kobo
   с **объединением** папок. Внутри только собственная папка `daily-sync` и собственный
   файл меню `.adds/nm/daily-sync`. Существующий `.adds/nm/doc` не заменяй. Остальные папки и настройки не заменяй и не удаляй.
3. Скопируй `.kobo/KoboRoot.tgz` в существующую `.kobo` на Kobo. Если там уже лежит
   другой `KoboRoot.tgz`, сначала заверши его установку; два пакета этот слот не поддерживает.
4. Безопасно извлеки диск, отключи кабель и дождись установки и перезагрузки.

**Первый запуск — на паузе:** в пакете есть `.adds/daily-sync/paused`, поэтому мод
сначала только подключает обработчики и пишет статус. NickelMenu и NickelDBus
не требуются. Если NickelMenu уже установлен, появятся три пункта Daily Sync.

В настройках Kobo отключи встроенную ежедневную автосинхронизацию: за ежедневный
запуск теперь отвечает DailySync, и отдельное пробуждение по штатному расписанию не нужно.

## Первое испытание

1. Находясь рядом с домашней Wi-Fi сетью, выбери **Daily Sync - resume** в NickelMenu.
   Если NickelMenu нет, по USB удали только файл `.adds/daily-sync/paused` и безопасно
   извлеки диск. Для гарантированного запуска можно один раз усыпить и разбудить Kobo.
2. Дай устройству закончить обмен. После этого проверь, что Wi-Fi выключен.
3. По USB открой `.adds/daily-sync/status.txt` и `.adds/daily-sync/daily-sync.log`.
   Ожидаемый результат — `DONE: full sync confirmed; Wi-Fi disabled`, а в
   `last-success.txt` — сегодняшняя дата по часам Kobo. Для новой версии нужно отдельно проверить ручное исключение.
4. Нажми штатную кнопку синхронизации Kobo в этот же день: в журнале ожидаются
   `MANUAL_REQUEST`, `STARTED`, `SUCCESS_SIGNAL` и `DONE`. Сеть не должна отключаться
   до завершения обмена. Затем ещё раз усыпи и разбуди Kobo. В этот день нового полного запуска быть не должно;
   в журнале ожидается `ALREADY_DONE`. Сравни с запросами в логе Autocaliweb.
5. Для дополнительного теста используй **Daily Sync - sync now**. Без NickelMenu
   можно создать пустой `.adds/daily-sync/sync-now` по USB и извлечь диск, либо удалить
   `last-success.txt` и разбудить читалку. Книги и базу трогать не надо.

Если появится `UNCONFIRMED`/`FAILED`/`INACTIVE`, нужны `status.txt` и `daily-sync.log`.
В этих собственных журналах мод не записывает адрес сервера, токены, названия книг,
пароли и идентификаторы пользователя. Дату и часовой пояс читалки следует выставить правильно.

## Пауза, ручная сеть, удаление

- **Пауза:** пункт **Daily Sync - pause**, либо создание файла `.adds/daily-sync/paused`.
  Затем Wi-Fi можно включать штатно. Если обмен уже идёт, текущая попытка сначала
  завершается с отключением сети; пауза действует для следующих действий.
- **Возобновить:** пункт **Daily Sync - resume**, либо удалить `paused`.
- **Удалить мод:** создать пустой `.adds/daily-sync/uninstall` и перезагрузить Kobo.
  NickelHook удалит собственную библиотеку; мод удалит свой файл NickelMenu.
  Другие моды не затрагиваются. Собственную папку `daily-sync` можно убрать после перезагрузки.
- Альтернативное удаление: удалить `.adds/daily-sync/installed` и перезагрузить.
- После удаления включи Wi-Fi вручную и при желании верни штатную автосинхронизацию.

## Исходники и проверки

Сборка использует NickelHook (MIT), исходники и лицензия находятся в `vendor/NickelHook`.
Никаких изменений в загрузчик, ядро, системные сценарии запуска и прошивочные
библиотеки на диске пакет не вносит. Устанавливается отдельный Qt-плагин в
`/usr/local/Kobo/imageformats/libdailysync.so`; перехват двух методов происходит в памяти.
NickelHook предоставляет штатный механизм удаления и пятисекундный failsafe при запуске.

Контейнер сборки: `ghcr.io/pgaskin/nickeltc:1.0`, digest
`sha256:3296eb400d270cfd26f5773ab09625d4469f85680b3a191951dfb78d8ade7840`.

```sh
g++ -std=c++11 -Wall -Wextra -Werror tests/policy_test.cc -o /tmp/daily-policy-test
/tmp/daily-policy-test
python3 tests/verify_firmware.py /path/to/official/libnickel.so.1.0.0
```

Проверка ELF читает таблицу символов и метаданные Qt без исполнения прошивки.
Она подтверждает наличие функций и сигналов, но не заменяет запуск на устройстве.
Исходная библиотека прошивки и сама официальная прошивка в пакет не включены.

- Официальная прошивка Kobo: https://ereaderfiles.kobo.com/firmwares/kobo7/Sep2026/kobo-update-4.38.23828.zip
