# Security and private data

This experimental plugin runs inside the stock reader process. Only the exact
Forma/firmware combination documented in README is targeted; no release currently
has a maintenance or security-update guarantee.

Do not post tokens, Wi-Fi passwords, full backups, account/book databases or private
server logs in public issues. The plugin's own log records state transitions and
local timestamps, but review all attachments before sharing them.

Use GitHub's private vulnerability reporting if it is enabled on the repository.
Otherwise open an issue asking for a private contact route without disclosing
sensitive details or an exploit. Ordinary sync failures belong in bug reports.
